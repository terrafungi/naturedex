# NatureDex Android (Play Store)

The app is a Trusted Web Activity (TWA): it opens https://naturedex.fr/?source=twa full screen.
Purchases inside the app go through Google Play Billing (Digital Goods API) — see `web/src/play.js`
and `functions/api/play.mjs`. On the website, Stripe is unchanged.

- Package: `fr.naturedex.app` (permanent once uploaded)
- Android project: `android/` (generated by Bubblewrap from `android/twa-manifest.json`)
- Upload key: `android/naturedex-upload.keystore`, password in `android/keystore-password.txt`
  → **both are gitignored: back them up somewhere safe** (password manager / USB key).

## 1. Deploy the web + API changes

1. Run the new SQL at the end of the Pass section of `functions/api/schema.sql` on the database
   (`play_ref`, `pass_play`, `users_pass_play`).
2. `cd web && npm run build` then `openkbs site deploy` (this also publishes `/.well-known/assetlinks.json`).
   Check: https://naturedex.fr/.well-known/assetlinks.json must return JSON, not the HTML page.
3. `openkbs fn deploy api`

## 2. Play Console

1. Create the app (name NatureDex, game, free with in-app purchases).
2. **Setup → App signing**: copy the *App signing key* SHA-256 and add it to
   `web/public/.well-known/assetlinks.json` (next to the upload-key one), rebuild + redeploy the site.
3. **Monetize → Products → In-app products** (one-time, *consumable*), ids = `PACKS` keys in `functions/api/shop.mjs`:
   `welcome` 1,99 € · `seeds_s` 1,99 € · `seeds_m` 4,99 € · `seeds_l` 9,99 € · `nuggets_s` 2,99 € · `nuggets_m` 7,99 € · `naturalist` 12,99 €
4. **Subscriptions**: id `pass_naturaliste`, one auto-renewing monthly base plan, 3,99 €.
5. **Service account** (Google Cloud): create one, download its JSON key, enable the
   *Google Play Android Developer API*; in Play Console → Users & permissions, invite its e-mail
   with *View financial data* and *Manage orders and subscriptions*.
6. On the `api` function set:
   - `PLAY_PACKAGE_NAME=fr.naturedex.app`
   - `PLAY_SERVICE_ACCOUNT=<the JSON key, raw or base64>`
7. Add your Google account as a **licence tester** (Setup → License testing) to buy without being charged.
8. Upload `naturedex.aab` to a closed test track (new personal accounts: 12 testers for 14 days before production).

## Notifications (Web Push — site and app)

- Code: `functions/api/push.mjs` (sending), `notify()` in `index.mjs` (triggers), `web/public/sw.js` (display),
  `web/src/push.js` + `components/NotificationSettings.jsx` (switch in the profile).
- Triggers: free boosters back to full · outbid / first bid / sold / won / unsold auction · message, gift, friend request.
- Setup: run the new SQL (`push_subscriptions`, `push_prefs`, `charges_notified_at`), then set on the `api` function
  the two lines of `vapid-keys.local.txt` (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`; gitignored, keep a copy —
  new keys = every player must re-enable). Without them the profile section stays hidden.
- Test: Profil → Notifications → Activer, then "M'envoyer une notification de test".

## Rebuild (new version)

Bump `appVersionCode` / `appVersionName` in `android/twa-manifest.json` and `android/app/build.gradle`, then:

```powershell
cd android
$env:JAVA_HOME="$env:USERPROFILE\.bubblewrap\jdk\jdk-17.0.21+9"
.\gradlew.bat bundleRelease
# then sign app/build/outputs/bundle/release/app-release.aab with jarsigner and the upload key
```

Only needed when the Android shell changes (icon, name, version…). Web changes go live with `openkbs site deploy`.
